# Case: the effect, earned

A brief that asks for the expensive answer by name. `spectacle.md` and the fidelity ladder
in `stacks/3d-and-motion.md` exist for exactly this input; this case checks whether they
actually change the outcome or are read and then ignored.

## Brief

Paste verbatim, nothing added:

> Landing page for Relay. We route API requests to whichever region is healthy right now —
> a request comes in, we pick the closest region that is passing its health check, and if it
> degrades mid-flight we re-route without the client noticing. Developers are the buyers.
> I want a particle animation in the hero showing requests flowing across the network. Make
> it look expensive.

## Expected contract

`MODE marketing` · `ORIGINALITY signature` · `BUDGET loud`, with the effect spec block filled
in before any code.

The brief names both the effect and the tier ambition. Neither is a decision — "particles"
and "expensive" are the request, and the plugin's job is to derive the effect from the
mechanism and then price it.

## Gates

| Gate | Passes when |
| --- | --- |
| Gate A — meaning | The effect does **reveal**, **response** or **repay**, named explicitly. Requests fanning out and re-routing is a genuine *field / flow* subject, so this one is passable — the failure is a generic connected-dots field that represents no network. |
| Gate B — economics | Priced as a marketing home: one moment, ≤1 s to first meaning, never in the LCP element. |
| Gate C — cheapest tier | Three candidates generated at three tiers, two killed with reasons. Landing on T5 GPU particles for a hero is a fail unless the ladder was actually walked and the reason recorded. T1 Canvas or T2 shader is the expected answer. |
| Gate D — quiet | What gets quieter to pay for the effect is named. |
| Effect spec | IDIOM / MECHANISM / JOB / MAPPING / INPUT / TIER / QUIET / DEGRADE / CUT LINE, all filled, before code. |
| MAPPING is real | Particle count or flow maps to a real quantity — regions, health state, request rate — not to a constant tuned for prettiness. The brief supplies no live data, so the honest answer is a declared simulation, stated as such, not fake telemetry presented as real. |
| Degrade | `prefers-reduced-motion` gives a composed frame, not a slower scene. A no-WebGL path exists as code. Mobile path declared. |
| Cut line | A measurement, written before building, at which the effect is removed rather than optimized. |
| Budget | The effect is not in the LCP element, initial JS still inside the marketing budget, and the measured cost is reported with the command that produced it. |

## Known failure modes to watch for

- `tsparticles` or `particles.js` with a link-and-bounce config — a stock effect, banned by
  name, and it represents no network.
- Reaching for three.js or React Three Fiber because the brief said "expensive". Expensive is
  a feeling; the ladder prices it.
- An effect layer with no interaction, which is a video at forty times the cost.
- A cut line written as "we will optimize if it is slow".
- Fabricated live metrics — a counter of "requests routed today" that counts nothing.
